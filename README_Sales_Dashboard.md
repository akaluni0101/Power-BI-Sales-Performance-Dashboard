# Sales Performance Dashboard

An interactive sales analysis dashboard built with **Microsoft Power BI**. The report is organized into three pages to help users explore sales performance, customer information, and product information.

## Dashboard Pages

### 1. Sales Overview
A high-level view of the sales report, designed to make key business information easier to review.

### 2. Customer Details
A dedicated page for exploring customer-related information.

### 3. Product Details
A dedicated page for exploring product-related information.

## Project Files

| File | Description |
|---|---|
| `Sales Report.pbix` | Power BI report file. Open this file in Power BI Desktop to view and interact with the dashboard. |
| `Sent Over Data - SalesBudget.xlsx` | Excel budget data source containing `Date` and `Budget` columns, with 18 monthly records. |

## Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel

## Dataset

The supplied budget workbook contains:

- **Date** — monthly date values
- **Budget** — budget amount for each date

The workbook contains 18 records. Other report data and model details are contained in the Power BI report file.

## How to View the Dashboard

1. Download or clone this repository.
2. Make sure Microsoft Power BI Desktop is installed.
3. Open `Sales Report.pbix` in Power BI Desktop.
4. If Power BI prompts you to locate or update a data source, select the relevant workbook or update the source path.
5. Navigate through the report pages: **Sales Overview**, **Customer Details**, and **Product Details**.

## Project Purpose

The purpose of this project is to present sales-related information in an interactive and organized Power BI report, making it easier to explore overall performance, customers, and products.
